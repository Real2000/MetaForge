## 一、账号与登录

**Q1. 忘记密码怎么办？**
管理员在后台「用户管理」→ 对应账号「重置密码」；重置后该账号下次登录强制改密。若 admin 自己忘密且无其他管理员，需在服务器上执行 `node scripts/reset.js` 清库重建（⚠️ 数据会清空，先确认有备份）。

**Q2. 为什么首次登录强制改密？**
平台安全机制：种子账号与重置密码均使用弱口令并打 `must_change_pwd` 标记，首次登录强制设置强密码。改一次后长期有效。

**Q3. 提示「登录尝试过于频繁」？**
登录接口按 IP 限流（10 次/分钟）。等 1 分钟再试；多人共出口 IP 的内网建议错峰登录。

**Q4. 账号被停用是什么表现？**
停用立即生效：已有登录态失效，登录被拒。找管理员在「用户管理」重新启用。

## 二、部署与启动

**Q5. 端口 3210 被占用？**
`lsof -i :3210` 找到占用进程结束它；或用环境变量换端口：`PORT=3211 npm start`（Docker 路径改 compose 的 ports 映射）。

**Q6. 双击「启动平台.command」提示找不到 Node？**
脚本会自动探测 Homebrew/nvm/volta 等常见位置；都没有时装 Node ≥ 18（官网 LTS 或 `brew install node`），装完重双击。

**Q7. npm install 失败 / 原生模块编译报错？**
多为网络或编译工具链问题：① 换镜像 `npm config set registry https://registry.npmmirror.com`；② macOS 装 `xcode-select --install`；③ Linux 装 `build-essential python3`。Docker 路径已在镜像内处理。

**Q8. Docker 构建很慢或失败？**
多阶段构建首次需下载基础镜像与编译原生模块（约 5-10 分钟）。国内可配置 Docker 镜像加速器后重试 `docker compose build --no-cache`。

**Q9. 想把数据搬到新机器？**
整体迁移：打包 `data/` 全目录（**必须含 secrets.json**，否则已加密的模型 Key 全部作废）+ `public/uploads/`，新机部署代码后放回原位启动。参考根目录 Docker 数据卷映射方式。

**Q10. 怎么重置整个平台回到演示数据？**
`node scripts/reset.js`（删 data/ 目录）→ 重启服务自动重建全套种子数据。

## 三、模型与对话

**Q11. 对话回复是「模拟回复」，怎么回事？**
模型供应商未配置 API Key 时，平台自动降级为模拟回复模式（功能链路完整、内容为占位）。管理员到后台「模型接入」→ 编辑供应商 → 填入真实 Key 即可启用真实模型。

**Q12. 如何配置模型供应商的 Key？**
后台「模型接入」→ 编辑 → API Key 填入保存。Key 落盘自动 AES-256-GCM 加密，回显只露尾 4 位；编辑时留空保存不会覆盖已有 Key。

**Q13. 模型下拉里的「（我的）」「（演示）」是什么意思？**
「我的」= 你在「我的模型」接入的自有模型源（自带 Key 优先路由）；「（演示）」= 供应商未配 Key 的演示模型。

**Q14. 支持 embedding / 图片 / 语音模型吗？**
支持。模型按类型自动分类（chat/image/video/tts/embedding），对应首页技能与知识库向量检索。

## 四、智能体

**Q15. 创建的智能体别人看不到？**
新智能体默认草稿状态，需管理员在后台发布（或走审核流）后全员可见；创建者本人随时可用。分类决定归属展示：企业智能体/数字员工/部门AI助理/其他，创建时在哪个分类下点新增就默认哪个类型。

**Q16. 免费版最多几个智能体？**
社区版软上限 3 个（达到后创建返回升级提示，不硬拦）。已发布智能体走分享/复制不受此限。

**Q17. 怎么把智能体嵌到自己网站？**
后台智能体管理 → 「嵌入」→ 配置域名白名单 → 生成 iframe 或 JS 浮窗代码。前置条件：已发布 + 已开启分享；白名单外域名会被 CSP 拒绝（防盗用）。

**Q18. 怎么生成 API 供外部系统调用？**
后台「API」→ 创建 Key（可绑定单个智能体限定作用域）→ 用 OpenAI 兼容格式调 `/openapi/v1/chat/completions`。限流：20 次/分钟/Key。

## 五、知识库与任务

**Q19. 知识库支持哪些格式？**
PDF / DOCX / TXT / MD / XLSX / CSV。扫描版 PDF（图片型）需平台部署 PaddleOCR 服务才能识别出文本；未部署时该类文件解析文本过短会明确提示。

**Q20. 召回测试怎么用？**
前台「知识库」→ 打开库 → 召回测试输入问题 → 查看命中分片与融合分/BM25 分/向量分。分数偏低时优先检查：文档是否已解析成功、分片大小是否合理。

**Q21. 定时任务的 Cron 怎么写？**
五段「分 时 日 月 周」：`0 9 * * *` 每天 9 点；`*/30 * * * *` 每 30 分钟；`0 18 * * 5` 每周五 18 点。非法表达式创建时即被拦截。非管理员上限 20 个启用中任务。

## 六、桌面操控（我的设备）

**Q22. 客户端配对流程？**
网页「我的设备」→ 生成 6 位配对码（120 秒有效一次性）→ Mac 客户端安装后输入配对码。配对码连续错误会触发锁定/限流（防暴力枚举）。

**Q23. 提示设备离线？**
客户端未运行或心跳超 30 秒。打开菜单栏助手确认在运行；检查与平台网络连通。

**Q24. AI 能操作我电脑的哪些东西？会被滥用吗？**
仅 13 项白名单操作（文件夹/目录/应用/通知/截图/剪贴板/键鼠/窗口/文件读写），**无任意命令执行**。每次高危操作对话中弹确认卡；全部操作留审计日志（管理后台可查）；键鼠类默认关闭需显式开启。路径限制在用户主目录内且拒绝系统保护区。

## 七、商业与安全

**Q25. 社区版和企业版差什么？License 怎么配？**
社区版含智能体/知识库/工作流/MCP/OpenAPI 全部基础能力；专业/企业版增加钉钉、LDAP、审核流、租户、无限配额等。License 文件放 `data/license.json` 即生效（详见 `docs/License密钥轮换指南.md`）。License 缺失/损坏自动降级社区版，不阻塞使用。
