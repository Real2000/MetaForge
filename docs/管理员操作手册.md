## 1. 📊 数据看板

**看什么**：活跃用户趋势（近 7 天）、Token 消耗趋势、智能体增长曲线、今日会话/消息量。

**操作要点**：
- 趋势图数据来自 messages/sessions 表，首次部署的种子数据已含 7 天历史
- 无需配置，打开即用；数据为当日近实时（非增量推送）

## 2. 🤖 智能体管理（核心模块）

**列表操作**（每行）：

| 操作 | 说明 |
|---|---|
| 发布 / 下架 | 草稿 ↔ 已发布；发布后前台可见可对话 |
| 通过 / 驳回 | 审核流（submit 状态的智能体）；驳回必填意见，提交人会收到驳回原因 |
| 编排 | 进入画布编排页（提示词 / 模型参数 / 工作流画布） |
| 文档 | 自动生成的 API 接口文档（由画布 Start/End 节点推导） |
| API | 创建/管理 OpenAI 兼容 API Key（可绑定单个智能体，见下方"作用域"） |
| 分享 | 生成免登录分享链接 |
| 嵌入 | iframe / JS 浮窗两种嵌入代码；**前置条件**：已发布 + 已开启分享 + 域名白名单（防点击劫持） |
| 导出 | 导出智能体配置 JSON（迁移用） |

**API Key 作用域**（安全机制）：创建 Key 时可绑定单个智能体——绑定的 Key 只能调用该智能体；不绑定为全域 Key。泄露一把 Key 的爆炸半径由绑定关系决定。

**从模板创建**：内置金融行业 6 套模板（信贷审查/合规问答/招标解析/反洗钱/投研摘要/客服质检），一键创建。

**导入配置**：从导出的 JSON 恢复智能体。

## 3. 👥 用户管理

- **新增用户**：用户名/昵称/角色（admin/user）/部门
- **重置密码**：重置后该用户下次登录走强制改密
- **启停**：停用立即踢下线（已有登录态失效）
- **弱口令标记**：系统自动扫描弱口令账号并标记强制改密（ mustard_change_pwd 机制）
- **配额**：用户级 Token 配额（0=不限），用量看板见「用量与配额」

## 4. 📚 知识库管理

- 知识库 CRUD、文件上传（PDF/DOCX/TXT/MD/XLSX/CSV）、分片解析状态
- 解析链路：常规解析 → 文本过短时 OCR 增强（需部署 PaddleOCR，未部署则静默跳过）→ 清洗 → 分片入库
- 归属：知识库按 owner 隔离，普通用户仅能挂载自己的库到智能体（后端强校验）
- 召回测试在**前台**知识库页（本模块面向管理）

## 5. 🔌 接入管理

- 对接 Coze / Dify 等外部平台的智能体，同步后统一纳管（列表中标「外部」标签）
- 已同步的智能体与自建的同权管理（发布/分享/API）

## 6. 🧩 MCP 服务

- 注册 MCP 服务器（名称/URL/鉴权）→ 平台自动发现其工具清单
- **信任分级**：`trusted=1` 的服务器其 low 风险工具在对话中免确认执行；默认整类按 high 处理（弹确认卡）
- **MCP 令牌**：为已发布智能体生成 MCP 访问令牌；令牌可绑定单智能体（作用域机制同 API Key）
- 智能体编排时可挂载 MCP 工具（mcp_servers 字段）

## 7. 🧠 模型接入

- 供应商 CRUD：名称 / base_url / API Key / 模型列表
- **未填 Key 的供应商对话自动降级为模拟回复**（链路完整、内容为占位）——首次部署后第一件事是给至少一家填真实 Key
- API Key 落盘加密（AES-256-GCM），回显仅尾 4 位掩码；「留空保存」不覆盖已有 Key
- 验证按钮：按模型类型选端点实测连通性
- 默认供应商：全局唯一（数据库唯一索引保证）

## 8. 🔐 密钥管理

- 画布 `{{env.XXX}}` 占位符的数据源（如 `{{env.WEATHER_KEY}}`）
- 仅管理员可写；任何接口不回读明文
- 供工作流节点引用外部服务密钥，避免硬编码进画布

## 9. 🛡️ 安全合规

- **敏感词库**：分类管理 + 批量导入/导出；输入拦截（命中即拒绝提问）/输出拦截（命中自动脱敏 ***）
- **拦截统计**：命中 TOP、累计拦截、PII 检出、注入拦截
- **安全事件审计**：PII 识别 / 提示词注入检测事件流水
- 建议初始化：先建 3-5 个分类，导入企业合规词表

## 10. 💳 用量与配额

- 用量报表：按用户/智能体/日期维度 Token 消耗
- 配额调整：用户级 quota_total（0=不限）；超配额时对话返回升级提示（402 软约束，不硬拦）
- 套餐体系见「商业化管理」

## 11. 📡 系统监控

- op_logs（操作审计）/ err_logs（错误日志）检索
- 桌面操控审计：本地桥操作（action 前缀「本地桥:」）含设备、操作类型、耗时、结果状态
- 日志保留 90 天自动轮转

## 12. 📈 运营监控

- **会话记录审计**：全平台最近 100 条会话，可下钻查看对话内容与链路追踪（调用模式/模型/耗时/Token/知识库命中/工具调用）

## 附录：智能体编排（画布）速查

从智能体管理「编排」进入：

- **节点类型 21 种**：start/end/llm/tool/code_sandbox/condition_loop/variable_assign/notification/http_request/database_query/answer/classifier/aggregator/iteration/assign/if-else/agent（子智能体）/image_gen 等
- **安全边界**（重要）：
  - `code_sandbox` Python 分支已禁用（fail-closed）；JS 走 vm 沙箱 + 静态危险模式拦截
  - `database_query` 仅允许白名单 SELECT（写语句/PRAGMA 拒绝）
  - `http_request` 走 SSRF 校验（私网/环回/云元数据拒绝），管理员可用 `AGENT_FETCH_ALLOW_PRIVATE=1` 放行内网
- **版本管理**：发布生成快照（published_workflow）；运行时优先快照，草稿不影响线上；支持版本回滚
- **发布即生效**：对话/API/MCP/定时任务/Webhook 全部走已发布快照
